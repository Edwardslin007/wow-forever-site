# 魔兽世界：无限 · 版本更新展示页

《魔兽世界：无限》（World of Warcraft: Forever）版本信息展示页面。
BlizzCon 2026 公布，2026 年 11 月 4 日全球同步上线。

## 特性

- **全屏分页式导航** —— 12 个模块各占一屏，支持滚轮 / 触摸滑动 / 方向键 / PageUp·Down / Home·End / 侧边索引
- **阵营双主题** —— 同一套 UI 架构下联盟（蓝银）与部落（红棕黑）两套皮肤，徽记与图腾均为手绘 SVG
- **官方 CG 混剪首屏** —— 6 段 1920×1080 片段循环播放，懒加载 + 相邻预取
- **单屏自适应** —— JS 逐屏测量并等比缩放，1920×1080 / 1600×900 / 1366×768 均完整无裁切
- **全页面粒子系统** —— Canvas 粒子随阵营实时变色，含鼠标引力交互

## 目录结构

```
index.html          页面结构 + 阵营徽记 SVG symbol
style.css           全部样式（设计令牌 / 分页 / 主题 / 自适应）
app.js              分页切换 / 阵营系统 / CG 混剪 / 粒子 / 自适应缩放
assets/video/       CG 片段 clip1-6.mp4（1920×1080 H.264，已 faststart）
```

## 本地运行

因使用 ES Module-free 的普通脚本与相对路径，可直接双击 `index.html` 打开；
推荐用本地服务器以获得更一致的媒体加载行为：

```bash
python -m http.server 8000
# 访问 http://127.0.0.1:8000
```

## 技术要点

- 视频以 `preload="none"` 懒加载，切到片段时才 `load()`，并预取相邻两段
- 缩放兜底用 `offsetHeight`（不受 `transform` 影响）测量，配合 `position:absolute` 精确居中
- 完整支持 `prefers-reduced-motion` 降级
- 响应式断点 1080 / 900 / 640px，移动端切换为抽屉式导航
